# Assignment
Module 1 Assignment - Computer Networks
## Title
How the Internet Delivers a Web Page
## Objective
To understand how a web page is delivered from a web browser to a web server using the TCP/IP protocol stack, DNS, HTTP, TCP, and Client–Server architecture.
## Solution
This assignment explains the complete process of loading a web page, including the TCP/IP protocol stack, DNS name resolution, HTTP communication, TCP reliability, Client–Server architecture, HTTP vs FTP comparison, cookies, and the communication flow diagram.
## Output
A detailed report explaining how the Internet delivers a web page, along with diagrams and flowcharts based on Module 1 concepts.
## Conclusion
This assignment helped in understanding how different networking protocols work together to deliver a web page efficiently and reliably over the Internet.
